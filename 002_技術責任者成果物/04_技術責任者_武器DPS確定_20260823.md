# 技術責任者決定記録：射撃武器の継続DPS確定

- 決定日：2026-08-23
- 決定者：役割3「技術責任者」
- 状態：確定・制作正典へ反映済み
- 対象：`001_設定資料/08_Weapon_Stats.md`
- 非対象：シナリオ、章進行、入手章、武器分類、武器設定、PPTX編集

## 1. 決定要旨

技術責任者正式資料 `002_スライド/03_技術責任者_技術要件定義_v1.pptx` 10ページのデータ契約に従い、射撃武器の継続DPSを「射撃間隔とリロードを含む値」として一意に確定した。

全13種の既存Damage、RPM、Magazine、Reloadを同式で再計算した結果、値そのものは武器間の瞬間火力、射撃テンポ、装填時間の個性と整合していた。一方、旧目標帯だけがリロードを実質的に除外した尺度になっていた。このため、武器実数を変更せず、射撃武器の継続DPS目標帯を確定式へ合わせて再定義した。

- 武器個性を決める基礎数値：変更なし
- 武器分類と役割：変更なし
- 入手章と章進行：変更なし
- 射撃武器の継続DPS目標帯：変更・確定
- 全13種の計算結果：13/13が範囲内

## 2. 計算契約

### 2.1 入力と式

```text
一発ダメージ   = Damage × pelletCount
射撃間隔       = 60 / RPM
全発射時間     = Magazine × 射撃間隔
弾倉総ダメージ = 一発ダメージ × Magazine
サイクル時間   = 全発射時間 + Reload
継続DPS        = 弾倉総ダメージ / サイクル時間
瞬間DPS        = 弾倉総ダメージ / 全発射時間
```

比較条件はレベル1、Standard、弱点なし、クリティカルなし、属性補正なし、防御前、全弾命中とする。

### 2.2 端点定義

1. 入力開始を`t=0`とし、初弾は操作応答のため即時発生してよい。
2. DPS計測では各射撃が`60 / RPM`秒の射撃占有時間を持つ。最終弾後の射撃硬直も一回分含める。
3. Reloadは最終弾の射撃占有時間が終了した直後に開始する。
4. Reload完了後、次弾が発射可能になった時点で一サイクルを終了する。
5. Magazineが1でもRPM由来の射撃占有時間を省略しない。
6. チャージ武器ではRPMをチャージと射撃後硬直を合算した基準間隔として扱う。
7. B12は8ペレット全命中、N90は最大チャージを基準とする。

この定義により、初弾を時間0とする実操作と、最終弾の発射間隔を数えるか否かという計測揺れを分離し、実装とCIが同じ値を返す。

## 5. CI契約

### 5.1 自動計算

- 入力：`Damage`、`pelletCount`、`RPM`、`Magazine`、`Reload`、`dpsBandId`
- 出力：`shotIntervalSec`、`magazineDamage`、`firingTimeSec`、`cycleTimeSec`、`burstDps`、`sustainedDps`、`dpsBandResult`
- `sustainedDps`の手入力および手入力値による上書きは禁止する。
- B12以外の`pelletCount`既定値は1とする。

### 5.2 判定

```text
inRange = minDps <= sustainedDps && sustainedDps <= maxDps
```

- 範囲判定は丸め前の倍精度値を使う。
- 範囲外はCI警告とし、武器ID、算出値、帯ID、下限、上限を必ず出力する。
- `Damage <= 0`、`RPM <= 0`、`Magazine < 1`、`Reload < 0`、`pelletCount < 1`、未定義`dpsBandId`はCIエラーとする。
- レベル、品質、STAT、弱点、属性、クリティカル、MOD、敵防御はレベル1基準の帯判定に含めない。

## 6. 判断理由

1. K11、T27、F60、M9、A31、I88は、リロード前の瞬間DPSでそれぞれの武器役割をすでに表現している。
2. B12、P6、N90、KXはDPSより単発、範囲、貫通、Breakを主価値とする。継続DPSだけを旧帯へ合わせると単発威力か射撃速度を過剰に上げ、武器分類の手触りを壊す。
3. Damageを一律増加すると敵HP、防御、部位耐久、弾薬経済、難易度の再調整が必要になる。今回の矛盾は尺度側にあり、既存実数を維持する方が影響範囲を限定できる。
4. 瞬間DPSと継続DPSを併記することで、制圧武器、単発武器、長リロード武器の価値を一つの数値へ潰さず比較できる。

# YTC Game - 設定・ストーリーまとめ v1

> Codex連携用。現時点のゲーム設定とStory
> 1～4をまとめた開発資料。未決定事項は今後変更可能。

## 1. ゲーム概要

-   3Dモデルを使った2.5D横スクロールアクション
-   主人公・敵は3Dモデル
-   マップから出撃フィールドを選択
-   1フィールドにつき10面
-   セーブ機能あり
-   難易度変更あり
-   操作ガイド／チュートリアルあり
-   将来的にオンライン協力プレイ対応
-   戦闘、装備収集、装備強化、ステージ攻略が中心

基本ループ：

`出撃準備 → マップ選択 → 装備選択 → 戦闘 → 装備回収 → 帰還 → 使用・強化・売却 → 次の任務`

## 2. 世界観

西暦〇〇年。テロ、戦争、武力紛争が頻発し、争いと無縁な国はほぼ存在しない。

社会の軍事化・機械化が進み、民間軍事会社（PMC）は戦場だけでなく日常社会にも浸透している。「学校の警備会社がPMC」ということさえ当たり前になっている。

PMCは戦闘だけでなく、警備、護衛、輸送、人員派遣など社会インフラの一部を担っている。

## 3. ytc

通称 **ytc**。「笑顔を届ける」会社。

-   小規模な民間軍事会社
-   所属人数：約15名
-   規模は小さいが所属メンバーのスキルが高い

主な仕事：

-   戦場における護衛任務
-   荷物の運搬
-   他部隊への派遣
-   高い技能を必要とする特殊作戦

## 4. 主人公

-   名前：山田
-   年齢：32歳
-   所属：ytc
-   ytcの小隊メンバーとして各種任務へ出撃する

## 8. 攻殻装甲 K1

Story 1で登場する新型攻殻装甲 Version 1。別名 **K1**。

-   アーマーを持つ
-   銃弾から装着者を保護
-   一定ダメージでアーマーが無力化
-   アーマー破壊後に銃弾を受けると山田は戦闘不能になる想定
-   ジャンプ可能
-   飛行可能
-   機甲兵用一般型ライフルを使用可能
-   超振動ソードを使用可能

Story 1終了後、追加データ収集のため山田／ytcがK1を預かる。

### 機甲兵

機械化戦闘装備を使用する強敵。

-   一般型ライフルでは装甲にダメージが通りにくい
-   超振動ソードは比較的有効
-   近接攻撃が非常に強力
-   機甲兵に殴られるとK1のアーマーが約半分削られる想定
-   対機甲兵用銃弾が有効

## 10. 敵対勢力

-   テロ組織
-   反社会組織
-   ライバルPMC
-   国軍

## 11. フィールド

マップから出撃先を選択する。

現時点の例：

-   雪山
-   砂漠

1フィールドにつき10面。

フィールドによって操作・能力にデバフが発生する。

例：

-   雪山：移動速度低下、地面が滑る
-   砂漠：エネルギー等への悪影響を検討

装備によって環境デバフを軽減・無効化できるシステムを検討する。

## 12. 装備ドロップ・成長

敵撃破時、一定確率で装備やアイテムがドロップする。

回収品は帰還後に：

1.  自分で使用
2.  装備強化に使用
3.  売却して資金化

レアリティ、ランダム性能、装備ロスト等は未決定。

# 13. Story 1 - K1性能試験

ytcと良好な関係にある装備開発会社から、新型攻殻装甲を試験してほしいという案件が入る。

山田がテスターとなり、**新型攻殻装甲 Version
1「K1」**を装備して訓練施設でテストを行う。

装備：

-   K1
-   機甲兵用一般型ライフル
-   近接用超振動ソード

K1にはアーマーがあり、銃弾を防ぐ。ただし一定量のダメージを受けるとアーマーが無力化される。アーマー破壊後に銃弾を受けると戦闘終了となる想定。

### ステージ内容

操作説明用のチュートリアルステージ。

敵：

-   動かないロボット兵
-   飛行ドローン

障害物を配置し、以下を順番に学ぶ：

-   移動
-   ジャンプ
-   飛行
-   射撃
-   近接攻撃
-   アーマー

### 終了

試験完了後、さらに実戦データを取るため、Version
1「K1」を山田／ytcが預かることになる。

# 14. Story 2 - 荷物運搬任務

K1を装備した山田が荷物運搬任務にアサインされる。

道中、強盗グループから襲撃を受ける。K1と一般的な強盗では戦力差が大きく、山田は圧倒的な力で返り討ちにする。

しかし強盗グループのリーダーが**対機甲兵用銃弾**を使用する。

命中率は高くないが、命中するとK1のアーマーが一気に約半分削られる。

対機甲兵用銃弾は、本来このような強盗グループが入手できるものではない。

### ドロップ

リーダー撃破後、対機甲兵用銃弾がドロップ。

山田が回収して確認するが、出所が分からない。

**本来入手困難な兵器・弾薬を誰かが世の中へ流している可能性**が浮上する。

### 終了

荷物を目的地へ届け、任務自体は成功。

------------------------------------------------------------------------

# 15. Story 3 - 病院襲撃

山田が暮らしている街の病院で定期受診していたところ、武装組織による襲撃事件に遭遇する。

襲撃者は5人程度だが、その中の一人が**旧式の機甲兵**を連れている。

5人と機甲兵は2階建ての病院を短時間で制圧。K1を装備していない山田も捕まる。

武装組織は大きな人的被害を出すことなく、特定の一人を確保。その人物に黒い布を被せ、外の包囲網を突破して離脱する。

山田は外に停めていた車に乗り、逃走車両を追跡。同時にytcへ事件を連絡する。

### 車両ステージ

通常の横スクロール戦闘ではなく、車を操作しながら逃走車両を追跡するレース／チェイス形式。

途中で敵から攻撃を受ける。

最終的に山田の車は**必ず撃破される**。

これはゲームオーバーではなくストーリー上の強制イベント。そのままイベントへ移行し、武装組織を見失う。

------------------------------------------------------------------------

# 16. Story 4 - 救出作戦

事件連絡を受けたytcは、自前の衛星を使って武装組織を追跡する。

しかし武装組織は途中で地下へ入り、衛星追跡ができなくなり見失う。

この世界では誘拐事件自体は珍しくないが、さらわれた人物は**大手装備開発会社の令嬢**だった。

当事者・協力者としてytcも関係者から呼び出される。

山田は誘拐事件だけでなく、病院にいた旧式機甲兵を気にしていた。

旧式とはいえ、通常の武装組織が簡単に手に入れられるものではない。Story
2の対機甲兵用銃弾も含め、

**何者かが兵器を相手を選ばず裏で販売・流通させている**

可能性を考える。

### ytcへの依頼

なぜか令嬢の救出作戦そのものをytcが任される。

相手には十分な資金があり、大手PMCへ依頼できるにもかかわらず、約15名の小規模PMCであるytcが選ばれた。

ytc側は「関わってはいけない案件ではないか」と疑う。

しかし依頼を拒否して大手企業との関係が悪化した場合、仕事、信用、経営、業界内での立場に影響する可能性があるため、リスクを理解しながら引き受ける。

### 廃墟ステージ

情報をもとに廃墟へ出撃。

敵と戦いながら内部へ進み、機甲兵と遭遇する。

一般型ライフルでは装甲にほとんどダメージが入らず苦戦する。

超振動ソードならダメージが通りやすいが、接近戦になる。

機甲兵に殴られるとK1のアーマーが約半分削られる。

プレイヤーは：

-   安全だがダメージの小さいライフル
-   高ダメージだが危険な超振動ソード

を使い分けて戦う。

機甲兵を倒したことで、山田／プレイヤーは**対機甲兵用銃弾の重要性**を実感する。

### 終了

廃墟を捜索するが、誘拐された令嬢も武装組織もすでにいない。

取り逃がした状態でStory 4終了。

# 18. Codex用・最初の戦闘プロトタイプ

完成版ではなく、まず基本戦闘を検証する。

### Player

Primitiveモデルでよい。

-   WASD：操作
-   Space：ジャンプ
-   Space長押し：飛行
-   左クリック：攻撃
-   R：リロード
-   T：銃器／近接武器切替
-   ライフあり
-   ライフ0でDown

### Enemy

Primitiveモデルでよい。

-   銃器で攻撃
-   Playerを認識
-   射程まで接近
-   適切な距離を維持
-   必要に応じて位置変更
-   射線が通る場合に射撃
-   ライフ0でDown

### 戦闘終了

PlayerまたはEnemyのどちらかがDownしたらRetryボタンを表示。

Retryで最初から再戦。

# 19. 用語（暫定）

-   **攻殻装甲**：山田などが装備する機械化戦闘装備そのもの。例：K1。
-   **機甲兵**：攻殻装甲等の機械化戦闘装備を使用する兵士。
-   **アーマー**：攻殻装甲の防御耐久値。残っている間は装着者を保護する。
-   **ライフ／HP**：装着者本人の戦闘継続能力。アーマーとは別。

フィールド攻略 × オンライン協力**

物語の初期軸：

**小規模PMC「ytc」が日常的な任務をこなす中で、本来出回るはずのない兵器の流通事件に遭遇し、次第に大きな事件へ巻き込まれていく。**

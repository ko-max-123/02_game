# ゲームルール設定

## 基本仕様

- **ジャンル**：3Dモデルによる2.5D横スクロール・装備収集アクション
- **基本人数**：1人
- **将来のオンライン協力**：最大4人
- **メインストーリー**：全20章
- **フィールド数**：10
- **1フィールド**：10ステージ
- **総メインステージ数**：100を制作目標とする（1章あたり原則5ステージ）。品質基準を満たせない場合は内容を薄めず、プロデューサー判断で統合・削減する。
- **想定本編時間**：25～35時間
- **1ステージ**：8～15分
- **1章**：45～75分
- **視点**：横方向を主にした固定奥行きの2.5D。演出時のみ限定的にカメラ角度を変える。

## 基本ゲームループ

```text
本社で会話・強化
→ ワールドマップでフィールド選択
→ 任務と装備プリセット選択
→ ステージ攻略
→ 敵・箱・目標から戦利品回収
→ 帰還
→ 使用・強化・分解・売却・証拠解析
→ 次の任務
```

## 基本操作

| 操作 | キーボード／マウス基準 | 内容 |
|---|---|---|
| 移動 | `A` / `D` | 左右移動 |
| 奥行きレーン | `W` / `S` | 対応区画のみ短い奥行き移動 |
| ジャンプ | `Space` | ジャンプ |
| 飛行 | `Space`長押し | ジェット上昇・ホバリング |
| 通常攻撃 | 左クリック | 現在武器の攻撃 |
|強攻撃／照準 | 右クリック | 近接強攻撃または精密照準 |
| 武器切替 | `T` | 射撃／近接切替 |
| リロード | `R` | 射撃武器リロード |
| 回避 | `Shift` | ダッシュ回避 |
| ガード | `Q` | 対応武器でガード |
| 戦術装備 | `1` / `2` | ユーティリティ使用 |
| 調べる／救助 | `E` | インタラクト |
| LARKスキャン | `F` | 第16章開始時は任務限定、章完了後に恒常化 |
| ポーズ | `Esc` | オフライン時は完全停止 |

正式版では全入力を変更可能にする。コントローラー操作を基準にUI導線も用意する。

## ステージ構造

一つのステージは次の要素から2～4個を組み合わせる。

- 導入・会話
- 移動・環境攻略
- 小規模エンカウント
- 目標ギミック
- 大規模戦闘またはボス
- 回収・脱出

同じステージで新ルールを二つ以上同時に初登場させない。

## ステージクリア条件

主目標を達成し、脱出地点へ到達すると成功。主目標は次のいずれか。

- 敵指揮官またはボス撃破
- 指定地点到達
- 護衛対象到達
- 防衛時間完遂
- 対象救出
- 情報・物資回収
- 追跡対象との距離維持
- 複数装置の停止

敵全滅を常に要求しない。任務目的と無関係な敵を避ける選択を認める。

## 失敗条件

- プレイヤー全員がDownし、蘇生手段がない。
- 必須護衛対象の耐久が0になり、修復猶予も終了。
- 必須防衛対象が全て同時に破壊される。
- 明示された時間制限を超える。
- 追跡対象との距離が許容時間を超えて離れる。

民間人一人の負傷で即失敗にはしない。被害は評価へ反映し、全滅や重要対象の喪失のみ失敗とする。

## チェックポイント

- 1ステージに1～3箇所。
- ボス直前には必ず設置。
- 到達時にHP・アーマー・弾薬を原則70%以上まで補給。
- 再開時、取得済み証拠品と開封済み隠し箱は保持する。
- 戦闘中のオートセーブは行わない。

## 任務評価

| 評価 | 条件の目安 | 報酬 |
|---|---|---|
| C | 主目標達成 | 基本報酬 |
| B | 主目標+サブ目標一部 | 素材+10% |
| A | 被害少、回収、時間のうち二項目達成 | 素材+20%、作業票 |
| S | 章固有の模範行動を達成 | 固有外観、初回特別報酬 |

評価軸はステージごとに表示する。秘密条件だけで低評価にしない。速度だけを万能評価にせず、救助・非致死・証拠・護衛状態を重視する章を作る。

## 戦闘ルール

- 射撃は安全で継続的、近接は危険だが装甲破壊と瞬間火力が高い。
- 敵の赤い攻撃はガード不能、黄色はジャストガード可能、通常色はガード可能。
- 同時に攻撃する一般敵は基準3体まで。高難度で4体。
- 画面外の敵は攻撃頻度を50%以下にし、攻撃時に警告表示を出す。
- プレイヤーの空中時間は敵対空攻撃とエネルギーで制限し、見えない天井で抑えない。
- リロードは回避または武器切替でキャンセル可能。装填完了前なら弾は入らない。
- 近接コンボは回避、ガード、武器切替でキャンセル可能。重い最終段のみ短い確定硬直を持つ。

## アーマーとダウン

- ダメージは原則シールド→アーマー→HPの順。
- アーマー0でも操作不能にはならないが、被弾の危険が大きくなる。
- HP0でDown。即座に死亡演出を出さない。
- ソロはHP0でチェックポイントへ戻る。自己蘇生は行わない。
- 協力時のみ蘇生ルールを使い、`EQP_UTIL_AUTO_REVIVE`はP5協力プレイ専用とする。

## ドロップと所有権

### ソロ

- 表示されたドロップはすべてプレイヤー所有。

### 協力

- 装備、素材、通貨はプレイヤーごとの個別ドロップ。
- 証拠品と主目標品は一人が取れば全員取得。
- 弾薬箱と回復箱は各プレイヤー一回ずつ使用可能。
- アイテムの早取り競争を発生させない。

## 装備持ち込み

- 任務前に最大3つのプリセットから選ぶ。
- フィールド情報に「寒冷」「高熱」「ジャミング」などの推奨タグを表示。
- 推奨装備がなくてもクリア可能な現地ギミックを用意する。
- ステージ中は補給地点で武器・ユーティリティを変更できる。
- ボス戦開始後の装備変更は不可。敗北後は変更して再戦できる。

## 難易度

| 名称 | 対象 | 敵HP | 敵ダメージ | 特徴 |
|---|---|---:|---:|---|
| Story | 物語優先 | 80% | 65% | 回避猶予+、照準補助強、失敗時補給 |
| Standard | 基準 | 100% | 100% | 推奨体験 |
| Veteran | アクション経験者 | 120% | 130% | 敵連携+、予告時間を少し短縮 |
| ORPHEUS | クリア後 | 145% | 165% | ボス追加行動、Elite配置変更 |

- 難易度は本社またはステージ選択時に変更可能。
- 難易度で物語、装備種類、エンディングを制限しない。
- 高難度は素材量、品質率、外観報酬が増える。
- 敵HPだけを極端に増やす「硬いだけ」の難しさを避ける。

## アシスト設定

難易度とは別に設定できる。

- 照準吸着：なし／弱／標準／強
- 近接自動振り向き：なし／標準
- 攻撃予告延長：0～50%
- 落下ダメージ：標準／軽減／なし
- 連打操作：連打／長押し
- 色覚プリセットと任意色
- 画面揺れ、点滅、モーションブラーの強度
- 字幕サイズ、話者名、背景濃度
- ゲーム速度：オフライン時のみ80%／100%

アシスト利用による報酬減少は設けない。

## ステルス・警報

- ステルスは一部区画の選択肢であり、ゲーム全体の必須ルールではない。
- 敵には「未認識→疑い→捜索→戦闘」の四状態がある。
- 警報0～3で増援、砲台、封鎖が変化。
- 発見後も端末停止や指揮兵撃破で警報を下げられる。
- 見つかった瞬間の自動失敗は、物語上必要な特殊任務以外では使わない。

## 護衛・救助

- 護衛対象はプレイヤーの少し後ろを歩き、危険時は遮蔽物へ入る。
- 対象を持ち上げて運ぶ区間は短くし、戦闘中は味方が一時支援する。
- 護衛HP0で即死亡せず「行動不能」になり、20秒以内の救助猶予を持つ。
- 救助対象の経路が塞がれた場合、ワープではなく近い安全地点で待機する。

## 車両ステージ

- 左右レーン、加速、減速、ジャンプ、車載射撃を使用。
- 通常装備の一部特性が車両へ変換される。アーマー→車体耐久、精密性→車載精度など。
- 第3章の車両破壊は唯一の強制敗北。専用UIとイベント遷移を使う。
- クリア後チャレンジでは通常の勝敗とタイム評価を使用する。

## フィールドと章の関係

- 一つのフィールドは10ステージ。
- 原則として前半01～05が奇数章、後半06～10が次の偶数章。
- フィールド前半クリアで後半を開放。10ステージ完了で異常任務とフリープレイを解放。
- 一度クリアしたステージは物語状態を固定した「記録再生」として再挑戦できる。
- 物語進行後に同じ地域へ戻るサブ任務は、変化後のマップを使う。

## セーブ

- オートセーブ枠1、手動セーブ枠3。
- 本社帰還、装備変更、ステージ開始、ステージ完了でオートセーブ。
- ステージ途中はチェックポイント一時保存を一つ持つ。
- セーブ対象：章進行、装備、素材、通貨、会話、証拠、評価、設定、チュートリアル状態。
- オンライン参加者は自分の装備・報酬・クリア記録を保存する。ホストの物語選択を上書きしない。

## オンライン協力（将来仕様）

- 1～4人。ストーリーはソロで完全攻略可能。
- 同じK1が複数いる矛盾を避けるため、ゲストはytcの量産支援外骨格「YCフレーム」として表示できる。各自画面では自分の外観を優先する設定も用意。
- 敵HP：2人150%、3人205%、4人250%。敵数と役割も増加。
- 味方ダメージなし。爆発の軽いよろけは設定で無効化可能。
- ムービーのスキップは全員投票。初見プレイヤーがいる場合は初期状態でスキップ不可。
- 通信切断時、ゲストをAIへ置換。再接続枠を5分保持。
- PvPは本作の対象外。

## New Game+

- 章、敵、フィールドを高レベル帯へ再調整。
- 装備、ランク、図鑑、外観を引き継ぐ。
- 証拠品と物語フラグはリセットし、再取得可能。
- 初回から全環境装備を使える代わり、敵に追加部位と行動を設定。
- New Game+限定で物語の核心を変えず、追加会話と開発ログを解放する。

## 経済・進行不能防止

- 標準難易度の通常クリア報酬は、使用した標準消耗品と修理費の120%以上。
- ストーリー必須装備は確定報酬または店の固定在庫にする。
- 装備売却で重要品を失わないよう、自動ロックする。
- 所持金0でも標準弾と最低限の補修材を支給する「ytc予備品」を使える。
- 特定ビルドだけを要求するボス前には、対策用Standard装備を試用できる。

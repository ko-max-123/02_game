# YTC Game 制作設定資料 レビュー結果

- レビュー日：2026-08-19
- 対象：`00_INDEX.md`～`12_ID_and_Terminology.md`（全13ファイル）
- 方針：元ファイルは変更せず、校正・相互参照・実装整合性の観点から修正候補を整理する。

## 総評

物語の全20章、10フィールド×10ステージ、ytcの15名、主要な固有名詞と章IDは、おおむね一貫している。特に、物語・フィールド・ボスの大枠は対応しており、制作正典としての骨格は明確である。

一方で、数値計算、装備枠、アイテムID、解放時期には実装結果を変える不整合がある。以下の「優先度：高」は、データ作成やプロトタイプ実装を始める前に確定したい。

## 優先度：高（実装前に修正・決定が必要）

### 1. プレイヤー出力倍率の説明と計算式が一致しない

- 該当：`07_Player_Stats.md:33`
- 該当：`08_Weapon_Stats.md:116`
- 問題：STAT 150は「約1.25倍」とされているが、記載式 `1 + (150 - 100) / (150 + 300)` の結果は約1.11倍になる。
- 推奨修正：1.25倍を設計目標とするか、現在の式を正とするかを決める。式を正とする場合は説明を「約1.11倍」へ修正する。1.25倍を正とする場合は、逓減を維持した新しい式と、STAT 50／100／150／200の期待値表を併記する。

### 2. 武器表から算出される継続DPSが目標帯と大きく異なる

- 該当：`08_Weapon_Stats.md:48-62`
- 該当：`08_Weapon_Stats.md:175-189`
- 問題：「リロード込み」の目標に対し、レベル1表からの概算継続DPSはK11が約106、T27が約107、I88が約117、B12が約55となる。目標は汎用AR 150～190、LMG 190～230、Shotgun 120～220であり、差が大きい。
- 推奨修正：目標が「リロードを除く瞬間DPS」なら注記を変更する。継続DPSが目標ならDamage、Magazine、Reload、RPMのいずれかを再調整し、計算例を1～2種掲載する。

### 3. アイテムIDの接頭辞規則が競合している

- 該当：`00_INDEX.md:75`
- 該当：`06_Loot_and_Items.md:12-20`
- 問題：INDEXはアイテムを `ITM_` と定義しているが、詳細資料は `CUR_`、`MAT_`、`CON_`、`DAT_`、`COL_` を使用している。実在する証拠品は `EVD_` で、INDEX例の `ITM_ANTI_ARMOR_ROUND` とも一致しない。
- 推奨修正：現在の詳細資料を正とするなら、INDEXの「アイテム」を通貨・素材・消耗品・情報・収集品へ分割し、各接頭辞を掲載する。`ITM_` を残す場合は用途を限定する。

### 4. 「戦術装備」「ユーティリティ」「消耗品」の関係が不明確

- 該当：`04_Weapons.md:9`
- 該当：`05_Equipment.md:13,151-160`
- 該当：`06_Loot_and_Items.md:81-91`
- 該当：`09_Game_Rules.md:44`
- 該当：`12_ID_and_Terminology.md:106`
- 問題：戦術装備2枠とユーティリティA/Bが同じ枠に見える一方、応急補修材と医療キットは `EQP_UTIL_*` と `CON_*` の双方に同じ名称・効果・回数で存在する。マスターデータを二重に持つのか、装備枠が消耗品を参照するのか判断できない。
- 推奨修正：正式名称を一つに統一する。例として「戦術装備スロットが `CON_*` を装填し、常時効果の小型装置のみ `EQP_UTIL_*` とする」と定義し、重複する回復アイテムを一本化する。

### 5. 緊急蘇生器のソロ対応が矛盾している

- 該当：`05_Equipment.md:159`
- 該当：`07_Player_Stats.md:160-164`
- 該当：`09_Game_Rules.md:123`

- 推奨修正：ソロで使用可能かを決め、3ファイルを統一する。ソロ使用可ならゲームルールにも例外を追記し、協力時との回復量・発動条件を分けて記載する。

### 6. K1の装備コスト上限の成長値が欠けている

- 推奨修正：Stage IIIを+15、Stage IVを+15とするなど、100→110→125→140へ到達する内訳をK1改修段階表へ追記する。

### 7. Penetrationの上限とMOD適用後の扱いが未定義

- 推奨修正：最終値を100でクランプするか、100超過を許可して定義範囲を変更する。計算式へクランプ位置も明記する。

### 8. 「刺突」属性が属性一覧に存在しない

## 確認できた整合項目

- 全20章が定義され、各章5ステージ、合計100メインステージの構成になっている。
- 10フィールドすべてに10ステージがあり、奇数章／偶数章の前半・後半対応も一致している。
- `01_Story_20_Chapters.md` と `12_ID_and_Terminology.md` の章ID・章タイトルは一致している。
- ytcメンバーは15名定義され、全員生存を正史とする方針もINDEX・人物資料・物語資料で一致している。
- `ytc`、K1、LARK、ORPHEUS、BLACK RAIL、神楽美緒、真壁宗一など主要固有名詞の表記は安定している。
- `00_INDEX.md` の分冊リンクは、対象12ファイルすべてに対応している。

2. アイテムID、戦術装備／ユーティリティ／消耗品のデータ構造を統一する。
3. 解放時期、K1改修値、蘇生ルールを統一する。
4. 第18～19章の進行と報酬を補完する。
5. 表記・誤字・色ルールを修正する。

# プレイヤーステータス設定

## 基本能力値

第1章開始時のK1標準構成を基準100として設計する。

| ID | 表示名 | 初期値 | 内容 |
|---|---|---:|---|
| `STAT_HP` | HP | 100 | 山田本人の戦闘継続能力。0でDown |
| `STAT_ARMOR` | アーマー | 200 | K1の防御耐久。原則HPより先に減る |
| `STAT_SHIELD` | シールド | 0 | 装備で追加。非被弾時に自動回復 |
| `STAT_ENERGY` | エネルギー | 100 | ジェット、シールド、ビーム等で共有 |
| `STAT_HEAT_MAX` | 熱容量 | 100 | 100でオーバーヒート |
| `STAT_STABILITY` | 安定性 | 100 | ノックバックとスタッガーへの耐性 |
| `STAT_LOAD_MAX` | 装備コスト | 100 | 装備パーツの出力上限 |
| `STAT_MOVE` | 地上速度 | 6.0 m/s | 左右移動の基準 |
| `STAT_JUMP` | ジャンプ力 | 8.5 m/s | 通常ジャンプの基準 |
| `STAT_JET_THRUST` | ジェット推力 | 12.0 | 長押し上昇の基準 |
| `STAT_JET_EFF` | ジェット効率 | 10/s | 一秒あたりの消費量 |

## 攻撃関連能力

| ID | 表示名 | 基準 | 効果 |
|---|---|---:|---|
| `STAT_BALLISTIC` | 射撃出力 | 100 | 弾道・爆発武器の基礎倍率 |
| `STAT_MELEE` | 近接出力 | 100 | 斬撃・振動・打撃の基礎倍率 |
| `STAT_ENERGY_PWR` | エネルギー出力 | 100 | ビーム・電撃の基礎倍率 |
| `STAT_PRECISION` | 精密性 | 100 | 拡散、弱点、空中射撃 |
| `STAT_BREAK` | 装甲破壊 | 100 | 部位装甲とスタッガーへの倍率 |
| `STAT_RELOAD` | 装填性能 | 100 | リロード時間への補正 |
| `STAT_SWAP` | 切替性能 | 100 | 射撃・近接切替時間への補正 |

数値100は倍率1.00。装備やスキルで150になれば対応性能は原則1.50倍ではなく、逓減式により約1.25倍とする。極端な一極化を防ぐ。

## 防御の処理順

1. 無敵時間、完全回避、ガード判定。
2. シールドがダメージを受ける。
3. アーマーがダメージを受ける。
4. アーマー0後、HPがダメージを受ける。
5. 一部の毒、出血、神経攻撃はアーマーを迂回しHPへ入る。

初期チュートリアルでは「アーマー破壊後の一発で戦闘終了」という分かりやすい特別ルールを使用できる。通常任務ではHP制へ移行する。

## アーマー、HP、シールドの回復

- **アーマー**：応急補修材、補給地点、味方支援で回復。自然回復なし。
- **HP**：医療キット、補給地点、伊吹の支援で回復。自然回復なし。
- **シールド**：4秒非被弾で毎秒最大値の15%回復。
- **エネルギー**：消費終了1秒後、毎秒15回復。
- **熱**：発熱終了直後から毎秒12低下。高熱環境と装備で変動。

## ガード、回避、スタッガー

- **回避**：入力開始から0.18秒の無敵。連続使用でエネルギー10消費。
- **ガード**：近接武器または盾対応装備で使用。ダメージを70%軽減し、安定性を消費。
- **ジャストガード**：命中前0.15秒以内。ダメージ0、安定性消費0、敵へスタッガー。
- **スタッガーゲージ**：通常は非表示。大きく蓄積した時だけ敵・プレイヤー共に表示。
- **スタッガー状態**：1.5～4秒行動不能。パイルバンカーなどの追撃機会になる。

## エネルギーと熱

エネルギーは「使える量」、熱は「使い続けられる時間」を表す。

- ジェット：エネルギーを継続消費し、少量発熱。
- ビーム：エネルギーと熱を両方消費。
- 電磁アーマー：被弾時にエネルギー消費。
- ジャマー：発動時に大きく発熱。
- 熱100で`STS_OVERHEAT`。5秒間、ジェット・ビーム・シールド回復が停止。
- エネルギー0でも地上移動、通常弾武器、近接武器は使用可能。完全な行動不能にはしない。

## 成長軸

### 1. オペレーターランク

- **上限**：30（本編クリア想定25～28）
- 任務、救助、初回敵解析で経験値を得る。
- 1ランクごとにスキルポイント1。
- HPや攻撃力を自動で大幅上昇させず、選択スキルを中心にする。
- ランク差による与ダメージ・被ダメージ補正は設けない。

### 2. K1改修段階

- 物語で進み、装備コスト、ジェット、LARK機能を解放する。
- メインストーリー進行の実感を担う恒久強化。

### 3. 装備強化

- 武器・防具レベルは1～10。
- 同じ章帯の装備ならレベル差3以内で実用になるよう調整。
- 古い愛用品は素材で現在章帯まで引き上げられる。

### 4. プレイヤースキル

- プレイヤー自身が、敵予告、武器相性、空中管理を学ぶ。
- 数値成長だけで序盤の敵を無視するゲームにしない。

## スキル系統

拠点ではクレジットなしで振り直せる。

### Assault（強襲）

- 近接コンボ追加
- 空中追撃
- 敵撃破時の短時間移動強化
- スタッガー中ダメージ増加

### Gunner（射撃）

- 反動制御
- リロードキャンセル
- 弱点マーキング
- 弾薬MOD携行数増加

### Vanguard（防衛）

- ガード性能
- アーマー修復効率
- 味方をかばった時のエネルギー回復
- 致命ダメージ耐性

### Support（支援）

- ジャマー、フレア、ドローン
- 救助とハッキング速度
- ドロップ回収範囲
- 協力プレイの蘇生性能

|---|---|---|---|

| `STS_FREEZE` | 凍結 | 移動・切替低下。最大蓄積で短時間停止 | 熱攻撃、寒冷装備 |
| `STS_SHOCK` | 感電 | エネルギー回復停止、シールド弱体 | 接地、絶縁装備 |
| `STS_JAMMED` | 妨害 | ロックオン、ミニマップ、支援停止 | 発信源破壊、ジャマー耐性 |
| `STS_CORROSION` | 腐食 | アーマー耐性が徐々に低下 | 補修材、洗浄地点 |
| `STS_POISON` | 毒 | アーマーを迂回してHP継続減少 | フィルター、医療キット |

## 環境パラメータ

| ID | 名称 | 蓄積時の影響 |
|---|---|---|
| `ENV_COLD` | 寒冷 | エネルギー回復と切替速度低下 |
| `ENV_HEAT` | 高熱 | 熱低下速度とビーム効率低下 |
| `ENV_DUST` | 砂塵 | 射撃精度とセンサー距離低下 |
| `ENV_TOXIC` | 有毒 | 毒蓄積、フィルター消費 |
| `ENV_EM` | 電磁 | HUDノイズ、支援装備クールダウン増加 |
| `ENV_WATER` | 浸水 | 地上速度低下、電撃伝播、熱冷却増加 |

環境は単純な常時デバフではなく、安全地帯、装備、ルート、敵への利用という対処手段を必ず持つ。

## Downと蘇生

### ソロ

- HP0でDown。
- 緊急蘇生器があればアーマー25%、HP30%で一度復帰。
- なければ最後のチェックポイントまたは任務リトライを選ぶ。

### 協力プレイ

- HP0で30秒のDown状態。這い移動とマーキングのみ可能。
- 味方が3秒救助するとHP30%で復帰。
- 各プレイヤーは補給地点の間で二回までDown可能。三回目は戦線離脱し、次の補給地点で復帰。
- 全員同時Downでチェックポイントへ戻る。

## HUD表示優先順位

常時表示：HP、アーマー、現在武器、残弾、エネルギー。  
条件表示：シールド、熱、状態異常、スタッガー、環境値、護衛対象。  
非戦闘時は武器情報を縮小し、目標と会話を読みやすくする。

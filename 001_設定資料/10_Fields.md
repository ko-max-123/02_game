# フィールド設定集

## フィールド共通ルール

- ワールドマップ上の作戦地域を「フィールド」と呼ぶ。
- 各フィールドは10ステージ。前半5ステージと後半5ステージで物語1章ずつを構成する。
- ステージ選択時に、環境タグ、主な敵、防御タイプ、推奨装備を表示する。
- 環境デバフには装備以外の現地対策も必ず置く。
- 10ステージ完了後、その地域のフリー任務、指名手配、素材探索を解放する。

## 環境相互作用

| 組み合わせ | 結果 |
|---|---|
| 水+電撃 | 範囲伝播。敵味方双方へ感電蓄積 |
| 寒冷+熱 | 凍結解除。急激な温度差で装甲へBreak |
| 砂塵+ビーム | 散乱により射程-15% |
| 毒ガス+爆発 | 一時的な燃焼爆発。使用後ガス濃度低下 |
| 強風+飛行 | 風向きへ加速。逆風時は消費増加 |
| ジャミング+有線端末 | 有線接続地点周辺だけHUD復旧 |

## アート・可読性ルール

- プレイヤーが立てる足場は、背景より明度差をつける。
- 即時危険は赤、環境危険は黄、操作可能設備は青、LARK対象は白緑で統一。
- 2.5Dで奥行きにあるだけの背景物と、当たり判定のある物を同じシルエットにしない。
- 雪、砂、煙で視界を落としても、敵の攻撃予告と重要UIは読める。
- 一フィールドに代表的な移動ギミックを一つ、戦闘ギミックを一つ、環境対策を一つ設定する。

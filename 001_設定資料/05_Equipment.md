# 防具・特殊装備設定集

## 装備構造

| 枠 | 内容 | 主に変化する能力 |
|---|---|---|
| フレーム | 攻殻装甲本体 | 基礎HP、基礎アーマー、出力、外観 |
| センサー | 頭部・肩部観測装置 | ロックオン、索敵、弱点、ジャミング耐性 |
| アーマー | 胸部・四肢装甲 | アーマー値、重量、属性耐性 |
| アーム | 腕部補助 | 反動、近接、リロード、重武器 |
| レッグ | 脚部補助 | 移動、ジャンプ、着地、滑り耐性 |
| バック | ジェット・シールド・大型装置 | 飛行、シールド、支援機能 |
| 戦術装備A/B | 任務内消耗品の装填枠 | `CON_*`の回復、弾薬、投擲物など |
| ユーティリティ | 再使用・常時型の小型装置 | `EQP_UTIL_*`のフレア、ジャマー、支援装置 |
| 環境対策1/2 | 地域環境への恒常対策 | 第5章で1枠目、第18章で2枠目 |

フレームは物語進行で強化し、ランダムドロップしない。その他の枠はドロップと製造の対象にする。

## 攻殻装甲K1

### `EQP_FRAME_K1` K1 Version 1

- **正式名称**：Kinetic Shell K-Series Independent Unit 1
- **通称**：K1
- **開発**：神楽ダイナミクス／安全核設計・神楽美緒
- **設計思想**：装着者の動作を置き換えず、拡張する。外部命令を拒否できる独立認証核LARKを持つ。
- **外観**：人型シルエットを保つ中量級装甲。白灰色の試験塗装に、ytc配備後は橙色の識別線が入る。
- **基本機能**：アーマー、神経補助、ジャンプ補助、ジェット飛行、射撃姿勢制御、近接振動同期。
- **弱点**：試験機のため各部規格が未成熟。高熱と強い電子妨害へ弱い。

## アーマー装備

### `EQP_ARMOR_CERAMIC` CERA-4積層装甲

- **設定**：最も普及した弾道防御板。
- **効果傾向**：アーマー+、弾道耐性+、重量は中。
- **弱点**：振動と連続する重打撃。

### `EQP_ARMOR_REACTIVE` RX反応装甲

- **設定**：強い衝撃を受けた瞬間に外板を切り離す。
- **効果傾向**：爆発・対機甲弾を一度大きく軽減。
- **制約**：発動後は補給地点まで効果を失う。

### `EQP_ARMOR_EM` EM電磁アーマー

- **設定**：導電層で弾体の姿勢とエネルギーを乱す。
- **効果傾向**：弾道・ビーム耐性。被弾時にエネルギー消費。
- **制約**：エネルギー切れでは通常装甲になる。

### `EQP_ARMOR_FLEX` FLEX可動装甲

- **設定**：装甲板を減らし、関節保護へ集中した軽量型。
- **効果傾向**：移動、回避、空中制御+。
- **制約**：最大アーマー-。

### `EQP_ARMOR_BULWARK` BW重装甲

- **設定**：辰巳が使う防衛用装甲のK1互換版。
- **効果傾向**：最大アーマーとスタッガー耐性が大幅増加。
- **制約**：ジャンプ、ジェット、切替速度が低下。

### `EQP_ARMOR_THERMAL` THM耐熱装甲

- **設定**：セラミック放熱板と冷却流路を持つ砂漠用。
- **効果傾向**：熱耐性、冷却速度、燃焼耐性。
- **弱点**：低温下では重量増加ペナルティ。

### `EQP_ARMOR_CRYO` CRY寒冷装甲

- **設定**：関節ヒーターと断熱ゲルを持つ雪山用。
- **効果傾向**：寒冷・凍結耐性、滑り軽減。
- **弱点**：高熱環境でエネルギー消費増加。

## シールドのルール

- シールドはアーマーの外側にある自動回復防御値。
- 4秒間被弾しなければ回復開始。アーマーは自然回復しない。
- 電撃はシールドへ強く、爆発はシールドへ弱い。
- シールドを採用すると装備コストとエネルギーを消費するため、常に最適ではない。

## 装備コスト

- K1には出力上限を表す**装備コスト**がある。
- 各パーツの合計が上限を超える構成は出撃不可。
- 軽装備は低コスト、シールド・高出力ジェット・重火器補助は高コスト。
- レベルアップでコスト上限を増やさず、K1の物語改修でのみ増やす。レベル上げだけで何でも同時装備できる状態を防ぐ。
- 上限はStage I 100、Stage II 110、Stage III 125、Stage IV 140で固定する。

## 装備破損とロスト

- 通常難易度では装備ロストなし。
- 任務中に耐久が0になると、その任務内だけ固有効果が停止する。
- 帰還後は少額で全修理。修理費で進行不能になる設計にはしない。
- 最高難度の任意ルール「現地調達」では、持ち込んだ消耗品と未回収ドロップのみ失う。固有武器・防具は失わない。

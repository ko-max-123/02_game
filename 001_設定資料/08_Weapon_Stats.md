# 武器ステータス・計算設定

## ステータス定義

### 射撃武器

| 項目 | 意味 |
|---|---|
| Damage | 一発または一ペレットの基礎ダメージ |
| RPM | 一分あたりの理論発射数 |
| Magazine | 一回の装填数。ビームは一回の冷却前容量 |
| Reload | 空状態からの基準リロード秒数 |
| Range | 距離減衰が始まるメートル |
| Penetration | 防御と装甲を抜く性能（0～100） |
| Break | スタッガー・部位装甲へ与える基準値 |
| Crit | 基礎クリティカル率 |
| Load | K1の装備コスト |

### 近接武器

| 項目 | 意味 |
|---|---|
| Light Damage | 弱攻撃一段目の基礎ダメージ |
| Interval | 弱攻撃一段目の開始間隔 |
| Reach | 標準攻撃の前方到達距離 |
| Penetration | 重装甲への通りやすさ |
| Break | スタッガー・部位破壊性能 |
| Guard | ガード時のダメージ軽減率 |
| Energy | 一回の標準攻撃で使うエネルギー |
| Load | K1の装備コスト |

### 近接コンボ倍率

- 弱攻撃1段目：表の100%
- 弱攻撃2段目：90%
- 弱攻撃3段目：125%
- 強攻撃：160%、Break 180%
- 溜め強攻撃：230%、Break 260%
- 空中弱攻撃：85%
- 空中強攻撃：着地を含め180%
- 射撃からの切替攻撃：110%、切替性能の補正を受ける

武器固有モーションがある場合は総ダメージがこの基準から±10%以内になるよう調整する。

## 基本ダメージ式

```text
最終ダメージ = 基礎ダメージ
             × 武器レベル倍率
             × 品質倍率
             × プレイヤー出力倍率
             × 命中部位倍率
             × 属性相性倍率
             × 防御倍率
             × スキル・状態補正
```

### 各倍率

- **武器レベル倍率**：下表。
- **品質倍率**：Standard 1.00 / Improved 1.03 / Specialist 1.07 / Prototype 1.11 / Signature 1.15。
- **プレイヤー出力倍率**：`1 + (対応STAT - 100) / (対応STAT + 300)`。
- **命中部位**：通常1.00 / 弱点1.50 / 強化弱点1.75 / 装甲部位0.70。
- **属性相性**：強い1.25 / 通常1.00 / 弱い0.65 / ほぼ無効0.20。
- **クリティカル**：通常1.50。弱点倍率とは乗算せず、高い方へ追加0.25する。

### 防御倍率

```text
有効防御 = max(0, 敵防御 - Penetration × 1.5)
防御倍率 = 100 / (100 + 有効防御)
```

例：敵防御100、Penetration40なら有効防御40、与ダメージは約71%。

## 距離減衰

- Rangeまでは100%。
- Range～Range×1.5で100%から65%へ直線低下。
- Range×1.5以遠は65%固定。弾を消滅させない。
- ショットガンはRange×1.5以遠でペレット拡散が急増。
- スナイパー、レーザー、レールは距離減衰なし。ただし照準中の被弾リスクを持つ。

## 装甲破壊と部位

- 部位装甲には独立した耐久値がある。
- Damageは部位HP、Breakは部位装甲耐久へ作用する。
- 部位装甲0で「破壊」。その部位の防御倍率を0.85～1.20改善し、敵行動を一つ弱体化する。
- 対機甲弾はDamageとBreakの双方へ補正する。
- ボスの必須部位破壊は最大三箇所。細かすぎる部位管理を避ける。

## DPSの目標帯

同レベル・Standard・弱点なし・防御前の継続DPS目安。

| 役割 | 目標DPS | 備考 |
|---|---:|---|
| 汎用AR | 150～190 | リロード込み |
| 高機動SMG | 150～180 | 近距離リスク込み |
| BR/DMR | 140～180 | 弱点命中で上回る |
| LMG | 190～230 | 移動・リロードの代償 |
| Shotgun | 120～220 | 距離で大きく変動 |
| 重火器 | 80～160 | DPSより瞬間・部位破壊 |
| 標準近接 | 170～210 | 接近リスク込み |
| 重近接 | 140～230 | 命中とスタッガーで変動 |

弱点、属性、改造を正しく合わせたビルドは基準の1.5～2.0倍まで到達してよい。

## バランス制約

- 一つの武器が射程、DPS、装甲破壊、機動性の四項目すべてで最高にならない。
- 対機甲弾を使った標準ライフルは重装甲へ有効になるが、専用重火器を完全には上回らない。
- 近接は高リスク相応の火力を持つ一方、敵の接触ダメージや不透明な当たり判定で罰しない。
- ビーム武器のDPSは高めでも、ジェット・シールドとのエネルギー競合で制限する。
- レアリティ差だけで低品質武器を即廃棄させず、固有挙動と改造で選ぶ余地を残す。
- PvE数値と将来の対人要素を共通化しない。本作の主軸は協力PvEとする。

# コア運用 v4

## 通常作業

1. 自分のタスクを確認。
2. 必要資料だけ読む。
3. 作業する。
4. 他領域が必要なら担当へ委譲。
5. 回答を受けて続行。
6. 必要なら校正。
7. 完了。

## 巡回

巡回は `08_巡回スケジュール.md` に従う。

巡回時は:
1. 自分の確認対象だけ見る。
2. 新規・更新だけ優先する。
3. 更新がなければ即終了する。
4. 001_設定資料を巡回目的で読まない。

## 依頼経路

第一選択:
直接委譲

第二選択:
GitHub Issue

## 禁止

- 30分巡回
- 全Issue巡回
- 全共有フォルダ巡回
- 全設定資料再読
- 全員同時稼働
- 中間PPTX乱発

# エージェント間連携 v4

## 直接委譲

依頼:
- From:
- To:
- 作業:
- 対象:
- 参照:
- 完了条件:
- 返却形式:

返却:
- 結論:
- 実施:
- 根拠:
- 影響:
- 未解決:

## GitHub Issue

使う場合:
- 別セッション
- 正式記録
- 後続
- ブロック
- 人間追跡

## Issue確認

巡回時、自分に関係するIssueだけ確認。

## 連鎖委譲

依頼先がさらに別担当を必要とした場合、
直接委譲またはIssue起票してよい。

## 禁止
- Issueを雑談チャット化
- 定期的な「作業中です」コメント
- 関係ないIssue巡回

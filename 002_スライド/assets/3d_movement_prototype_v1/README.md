# 山田／中央産業帯 Stage 01 3D移動確認プロトタイプ v1

## 目的

`000_エージェント共有読み物/02_タスク.txt`に基づく、デザインマネージャー担当の3D成果物です。

- 山田（K1装着状態）をゲーム内へ読み込む。
- 中央産業帯 Stage 01「起動確認」のデモフィールドを読み込む。
- 技術責任者がWASD移動とSpaceキーのジャンプを実装・確認する。

開発コードと入力処理は含みません。技術責任者が実装するための、エンジン非依存のデザイン資産です。

## ファイル

| ファイル | 内容 |
|---|---|
| `yamada_k1_prototype_v1.glb` | K1装着状態の山田。低ポリ、パーツ階層、移動確認用の簡易アニメーション3種 |
| `central_belt_stage01_demo_field_v1.glb` | 平地、低い障害物、段差、2 mギャップ、坂、開始・終了地点を含む試験区画 |
| `yamada_k1_prototype_v1.obj` | Unity標準インポート向けの山田静的フォールバック |
| `central_belt_stage01_demo_field_v1.obj` | Unity標準インポート向けのフィールド静的フォールバック |

## 共通仕様

- 主形式：glTF 2.0 Binary（`.glb`）
- 静的フォールバック：Wavefront OBJ／MTL
- 単位：1 unit = 1 m
- 上方向：`+Y`
- モデル正面：`+Z`
- フィールドの主要移動軸：`+/-X`
- レーン中央：`Z = 0`
- 外部テクスチャ・外部素材：なし
- 実在製品・第三者ロゴ：なし

## 山田モデル

- ルート：`YAMADA_K1_ROOT`
- 全高：約2.30 m
- 推奨キャラクター当たり判定：半径0.38 m、高さ1.86 mのカプセル
- 推奨カプセル中心：`(0, 0.93, 0)`
- 原点：足元中央
- デザイン：白灰色の試験装甲、黒鉛色の関節、ytc橙ライン、左右非対称部品、胸部の小さな笑顔マーク
- 簡易アニメーション：
  - `Idle_Prototype`
  - `Walk_Prototype`
  - `Jump_Pose_Prototype`

アニメーションは入力・遷移検証用の仮素材です。最終モーション品質を定義するものではありません。

Unityへ追加のglTFパッケージを導入しない場合はOBJ版を使用します。OBJ版にはアニメーションと`extras`メタデータがないため、当たり判定値と開始座標は本書を参照してください。

## デモフィールド

- ルート：`FIELD_CENTRAL_BELT_STAGE01_ROOT`
- 全体目安：32 m × 5.1 m × 8 m
- 推奨開始座標：`(-13.7, 0, 0)`
- 推奨終了座標：`(13.2, 0.8, 0)`
- 推奨カメラオフセット：プレイヤーから `(0, 3.8, 10.5)`
- 確認区画：
  1. 平地移動
  2. 高さ0.6 mの低い障害物
  3. 幅2.0 mのジャンプ用ギャップ
  4. 高さ0.2／0.4／0.6 mの段差
  5. 高低差0.8 mの坂
  6. 開始・終了マーカー

## ノード命名

- `RIG_`：山田モデルの可動階層
- `VIS_`：表示用メッシュ
- `COLLISION_`：フィールド当たり判定生成の対象
- `MARKER_`：開始地点、終了地点、ジャンプ区画、カメラガイド

各`COLLISION_`ノードの`extras`には、`box`または`convex`の推奨コライダー種別を格納しています。

## 技術責任者への受け入れ条件

1. 2ファイルを別々のシーン／Prefabとして読み込める。
2. 山田の足元原点を開始地点へ置ける。
3. WASDで移動し、進行方向に応じてモデルを左右へ向けられる。
4. Spaceキーでジャンプし、0.6 m障害物と2.0 mギャップを越えられる。
5. `COLLISION_`ノードから床・障害物・坂の当たり判定を作成できる。
6. カメラが2.5Dレーンを横から追従し、背景と当たり判定対象を識別できる。

## 再生成

Codex同梱Pythonで`tools/generate_3d_prototypes.py`を実行します。Pillow以外の追加パッケージやネットワーク取得は不要です。

# P0スタンドアロン戦闘プロトタイプ デザイン受入基準

- 担当：デザインマネージャー
- 作成日：2026-08-25
- 対象：山田／K1、中央工業帯、簡易敵、射撃エフェクト、被弾・撃破、最小HUD
- 判定目的：完成版の美術品質ではなく、1920×1080の2.5D画面で「自分・敵・足場・攻撃・結果」を即座に読めること

## 1. 必須基準

| 対象 | 合格条件 | 不合格例 |
|---|---|---|
| 山田／K1 | `yamada_k1_demo.obj`を使用。白灰装甲、暗色関節、細いytc橙、シアンのバイザー、左右非対称部品が通常カメラ距離で判別できる | 全身を橙や赤にする、敵と同じ輪郭、白飛びで関節が消える |
| 中央工業帯 | `central_industrial_belt_demo.obj`を使用。明るい足場、暗い縁、黄＋三角形の危険、青＋縦長形状の操作設備、低彩度の背景を維持する | 背景の高架や倉庫が足場に見える、戦闘面の背後に強い赤・橙が常時重なる |
| 簡易敵 | 訓練ロボ／模擬ライフル兵として、K1より角張った矩形胴体、低い頭部、赤い三角センサーを持つ。胴体は暗い灰、所属橙とLARK白緑は使わない | K1の色替え、赤一色、細い線だけで敵を表す |
| 前後関係 | K1と敵はプレイレーンで最も高い輪郭コントラストを持ち、背景設備は一段暗く低彩度にする | 背景の窓・標識・煙突が照準や敵センサーより目立つ |
| 画面外攻撃 | 画面端マーカーと発射前表示の2種類で予告する。音がなくても方向が分かる | 見えない敵から無予告で被弾する |

## 2. 色・形の指定

| 用途 | 基準色 | 色以外の識別 |
|---|---|---|
| K1装甲 | `#C8CDD0` / `#E8E7E0` | 大面積の装甲板 |
| K1関節 | `#333B40` | 装甲の間に見える細い関節 |
| ytc／味方 | `#F28C28` | 細い斜線、笑顔マーク |
| 操作・バイザー | `#39A9DB` / `#3AA8C7` | 四角表示、縦長装置 |
| LARK | `#BDECCB` | 二重リング、短いパルス |
| 敵対 | `#E54848` | 三角、山形、鋭い括弧 |
| 環境危険 | `#E3B341` | 三角歯、斜線 |
| 即時危険 | `#D94343` | 赤い低床、尖った先端 |
| 背景 | `#657079` / `#3C464C` | プレイ面より奥、細部と彩度を抑える |

色をモノクロ表示へ変えても、K1、敵、危険床、操作設備を輪郭だけで区別できること。

## 3. 弾丸・戦闘エフェクト

### プレイヤー射撃

- 弾丸：白い短い芯＋橙の尾。先端は丸みのある細い菱形。
- マズルフラッシュ：白黄の短い前向き円錐。K1の腕・頭部を隠さない大きさ。
- 敵への命中：白黄の放射状火花＋命中点の短い白フラッシュ。

### 敵射撃

- 弾丸：赤い芯＋暗色の外縁。先端は鋭い三角形。
- 発射予告：敵センサーの赤点滅、または短い赤照準線を発射前に表示。
- マズルフラッシュ：赤橙の四尖形。プレイヤー弾と静止画でも区別できること。

### プレイヤー被弾

- 命中位置に白橙の装甲火花を出し、画面端へ赤い方向括弧を一度だけ表示する。
- HUDのアーマー減少を同時に見せる。全画面を不透明な赤で覆わない。
- 連続被弾でもK1、敵、照準が0.2秒以上隠れ続けない。

### 敵撃破

- 流血を使わない。赤い敵センサーを消灯し、胴体を低彩度化して沈む／後方へ崩れる。
- 撃破火花は命中火花より大きくするが、次の敵を隠さない。
- 撃破と同時に残敵数を更新する。

## 4. P0 HUD

| 要素 | 配置・表現 | 合格条件 |
|---|---|---|
| 生存 | 左下。橙の分割アーマーバー＋白いHPバー。低HP時だけHPを赤く点滅 | 被弾直後に減少箇所が分かる |
| 残敵 | 右上。赤い下向き山形＋`残敵 3`。32px以上 | 敵撃破の瞬間に更新し、背景から読める |
| 操作 | 画面下中央。半透明の暗色帯に、実装済み入力だけを一行表示 | 24px以上。キャラクター、足場、照準と重ならない |
| 被弾方向 | 画面端の赤い括弧。被弾方向だけに短時間表示 | HUD文字や照準を覆わない |
| 勝利 | 残敵0で中央に`MISSION CLEAR`。白文字＋細いytc橙線＋暗色半透明帯 | 戦闘中に誤表示せず、最終撃破から1秒以内に読める |

HUDは左右端から48px以上内側へ置く。操作表示例は`A/D 移動　W/S 奥行き　Space ジャンプ／飛行　LMB 射撃　R リロード`とし、未実装操作は表示しない。

## 5. 受入チェック

- [ ] 1920×1080の通常プレイ画面で、1秒以内にK1と敵を指し分けられる。
- [ ] グレースケール画像でも足場、背景、危険、操作設備を形で判別できる。
- [ ] プレイヤー弾と敵弾を、色を見なくても先端形と尾の形で区別できる。
- [ ] 敵の発射前表示、飛翔、命中の順序が読める。
- [ ] 被弾時に「方向」と「アーマー減少」が同時に分かる。
- [ ] 残敵数が各撃破で1減り、0で勝利表示へ切り替わる。
- [ ] マズルフラッシュ、命中、撃破エフェクトがK1や次の敵を長時間隠さない。
- [ ] 敵撃破に流血・死体損壊を使っていない。
- [ ] HUDが照準、キャラクター、足場、敵予告と重ならない。
- [ ] 背景の夕景・照明が、橙の味方識別と赤い敵警告を消していない。

## 6. P0では判定しないもの

リグ、正式アニメーション、UV/PBR、LOD、最終武器形状、シールド・熱・状態異常HUD、ドロップ、ボス演出、完成版サウンドはP0受入対象外とする。ただし、後工程で置き換えられることを理由に、上記の敵味方識別と戦闘可読性を省略してはならない。

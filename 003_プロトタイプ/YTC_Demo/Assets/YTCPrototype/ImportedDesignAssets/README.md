# YTC Prototype Design Assets

Unityでの移動・ジャンプ確認用に作成した、オリジナルの低ポリ3Dデモ資産です。山田はK1を装着した状態で表現しています。完成版のキャラクター、リグ、アニメーション、最終ステージ美術を代替するものではありません。

## ファイル

| ファイル | 内容 |
|---|---|
| `Models/yamada_k1_demo.obj` | 山田／K1デモモデル。56オブジェクト、1,152三角形 |
| `Models/central_industrial_belt_demo.obj` | 中央産業帯の表示用デモフィールド。146オブジェクト、2,356三角形 |
| `Models/central_industrial_belt_collision.obj` | プレイ領域だけを簡略化したコライダー用メッシュ。14オブジェクト、168三角形 |
| `Materials/ytc_design_assets.mtl` | 全OBJ共通マテリアル。外部テクスチャなし |
| `Previews/*.png` | モデルとフィールドのプレビュー |
| `asset_manifest.json` | オブジェクト数、頂点数、三角形数、境界寸法 |
| `Source/generate_design_assets.mjs` | OBJ、MTL、SVGプレビューの再生成元 |

## 座標・寸法

- 単位：`1 OBJ unit = 1 meter`
- 軸：Y-up、Z-forward
- K1正面：`+Z`
- K1原点：足元中央。足裏が`Y=0`
- K1境界寸法：約`W 1.437 × H 2.002 × D 0.796 m`
- 表示フィールド全体：約`W 55.0 × H 11.73 × D 15.935 m`（背景設備を含む）
- プレイ／コライダー領域：約`W 40.0 × H 2.42 × D 6.0 m`
- プレイ床面：原則`Y=0`、奥行き帯は`Z=-3～+3`
- 推奨開始位置：`(-15.2, 0, 0)`
- 目標マーカー位置：`(18.0, 0, 0)`

## デザイン意図

### 山田／K1

- 中量級で、人間の関節位置を追えるシルエット
- 白灰の試験装甲、暗色関節、ytcの橙ライン
- 左肩の大型試験装甲、右前腕モジュール、左右差のあるジェットで試作機らしさを表現
- 胸部の補修痕、露出ボルト、小さな笑顔マークで「修理して使う現場装備」を表現
- シアンのバイザーと白緑のLARK部で、操作情報と安全認証を敵対色から分離

### 中央産業帯

- 白い試験施設、物流倉庫、貨物コンテナ、高架道路、工場煙突、夕方の工業地帯で構成
- 足場：白灰の厚いスラブ＋暗色の縁＋反復ノッチ
- 危険：黄の三角歯＋赤い低床。色を消しても尖った輪郭で識別可能
- 操作設備：青い縦長コンソール＋発光面
- 背景：プレイ領域より暗い材質で、`+Z`側へ分離
- ジャンプ確認用として、低障害物、三段ステップ、上り下り、`X=5～6`の短い溝を配置

## マテリアル

K1系は`K1_*`、ytc識別は`YTC_Orange`、LARKは`LARK_Mint`です。フィールド系は`Field_*`で統一しています。MTLの色だけでなく、形状・位置・反復パターンでも用途を判別できる設計です。PNGテクスチャは使用していません。

## Unity取り込みメモ

1. `DesignAssets`のディレクトリ構造を維持したままUnityプロジェクトの`Assets`配下へコピーしてください。
2. OBJのScale Factorは`1`を前提とします。
3. `yamada_k1_demo.obj`は未リグの静的デモモデルです。移動確認では親GameObjectへCharacterControllerまたはカプセルコライダーを設定してください。
4. フィールド表示には`central_industrial_belt_demo.obj`を使い、表示メッシュ自身へ自動コライダーを生成しないでください。
5. 当たり判定には`central_industrial_belt_collision.obj`を別GameObjectとして配置し、Rendererを無効化して静的MeshColliderへ使用できます。
6. MTLが自動解決されない場合は、`Materials/ytc_design_assets.mtl`を参照し、同名マテリアルへ割り当ててください。

## 制約

- スキニング、ボーン、アニメーション、UV、LODは未作成です。
- OBJは三角形化済み、ハードエッジ前提です。
- 移動・ジャンプ・カメラ・衝突検証向けのデモ品質です。
- 最終アートへ使用する場合はリトポロジー、リグ、UV、PBRマテリアル、LOD、物理形状の再制作が必要です。

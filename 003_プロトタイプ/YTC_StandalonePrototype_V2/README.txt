YTC STANDALONE COMBAT PROTOTYPE V2

Copy this entire folder to a Windows PC, then double-click YTC_CombatDemo_V2.exe.
Unity Editor and Unity Hub are not required. Keep the EXE, Data folder, DLL files, and runtime folders together.

A/D: Move, Space: Jump/hold Jet, Left Mouse/J: Fire, R: Restart, Esc: Quit
Enemy aim locks when the dashed warning appears. Move or jump before the projectile arrives.

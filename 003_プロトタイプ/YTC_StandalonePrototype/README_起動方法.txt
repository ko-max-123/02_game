YTC スタンドアロン戦闘プロトタイプ

起動方法
1. このフォルダ一式を同じ構成のままWindows PCへコピーします。
2. YTC_CombatDemo.exeをダブルクリックします。
3. Unity Editor、Unity Hub、追加インストールは不要です。

操作
- A / D : 左右移動
- W / S : 限定奥行き移動
- Space短押し : ジャンプ
- Space長押し : JET飛行
- 左クリック : マウス照準方向へ射撃
- J : 向いている方向へ射撃
- R : 戦闘を最初からやり直す
- Esc : 終了

配布時はYTC_CombatDemo.exeだけでなく、YTC_CombatDemo_Dataフォルダ、
UnityPlayer.dll、UnityCrashHandler64.exe等を含むこのフォルダ一式を渡してください。
